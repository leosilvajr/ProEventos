# Projeto de API com ASP.NET Core e Angular

## Descrição

Olá! Bem-vindo ao projeto de criação de uma aplicação web utilizando tecnologia API RESTful com o ASP.NET Core 6 e Entity Framework Core 5, juntamente com o framework Angular 11 e 12. Este projeto faz parte do curso ministrado por Vinícius Andrade.

## O Projeto Contém

- Introdução ao ASP .NET Core 5
- Introdução à Angular 11 e 12
- Implementação de uma RESTful API
- Características e conceitos essenciais do ASP.NET API MVC
- Profundidade no Entity Framework Core 5
- Criação de uma Web API em várias camadas

## Módulos

1. .NET Core 5
2. EF Core 5 - Introdução
3. Angular - Introdução
4. Angular - Interpolação, Diretivas e Binding
5. .NET 5 - Múltiplas Camadas
6. Angular - Organização, Rota, Alertas e Mais
7. Angular - Reactive Forms e Novo Layout
8. DTOs & Data Annotations
9. Angular - Registrando Evento
10. Angular e .NET - Eventos e Lotes
11. Upload de Imagens
12. ASP.NET Core Identity - Autenticação e Autorização (TOKEN - JWT)
13. Angular + .NET Core Identity + JWT
14. Paginação e Filtros
15. Palestrantes e Redes Sociais - Backend
16. Palestrantes e Redes Sociais - Frontend

## Tecnologias Utilizadas

- **ASP.NET Core 6**
- **Entity Framework Core 5**
- **Angular 11 e 12**

Antes de começar, certifique-se de ter o seguinte instalado em sua máquina:

## Instalação e Execução

Siga os passos abaixo para configurar e executar a aplicação:

### Backend (.NET Core 6)

1. Clone o repositório:
    ```bash
    git clone https://github.com/seu-usuario/seu-repositorio.git
    ```

2. Navegue até o diretório do projeto:
    ```bash
    cd seu-repositorio/Backend
    ```

3. Restaure as dependências e compile a solução:
    ```bash
    dotnet restore
    dotnet build
    ```

4. Aplique as migrations e atualize o banco de dados:
    ```bash
    dotnet ef database update
    ```

5. Execute a aplicação:
    ```bash
    dotnet run
    ```

### Frontend (Angular)

1. Navegue até o diretório do projeto Angular:
    ```bash
    cd seu-repositorio/Frontend
    ```

2. Instale as dependências do projeto:
    ```bash
    npm install
    ```

3. Execute a aplicação Angular:
    ```bash
    ng serve
    ```

4. Acesse a aplicação em:
    ```
    http://localhost:4200
    ```
